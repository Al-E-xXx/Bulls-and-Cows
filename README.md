# Bulls and Cows / Быки и коровы

Игра «Быки и коровы» — учебный проект RS School
([fullstack-engineering](https://github.com/rolling-scopes-school/tasks/blob/master/fullstack-engineering/tasks/bulls-and-cows/README.md)).
Полностью на TypeScript, без бэкенда и без UI-фреймворков: интерфейс строится кодом
через DOM API, логика — чистые функции в функциональном стиле.

## Правила

Компьютер загадывает код из уникальных символов выбранной длины и системы счисления.
Игрок угадывает; после каждой попытки получает оценку:

- **бык** — символ угадан и по месту,
- **корова** — символ есть в коде, но на другой позиции.

Победа — когда число быков равно длине кода.

## Возможности

- настройки: длина кода 2–6, системы счисления `bin` / `oct` / `dec` / `hex`
  (для двоичной доступна только длина 2 — символы уникальны), показ числа вариантов;
- фильтрация ввода: недопустимые и повторяющиеся символы отсекаются на лету,
  повторные попытки отклоняются с сообщением;
- история попыток, таймер раунда, экран результата;
- таблица рекордов: топ-10 отдельно для каждой пары «длина + система»,
  сортировка по попыткам, затем по времени; хранится в `localStorage`
  и устойчива к повреждённым данным;
- «Новая игра» — возврат к настройкам без перезагрузки страницы.

## Технологии

- **TypeScript (strict)** → ES-модули через `tsc`, без бандлера: браузер грузит
  `dist/main.js` как ES-модуль;
- **функциональный стиль**: чистые функции, иммутабельные обновления состояния,
  каррирование, мемоизация, рекурсия; вся неопределённость (случайность, время,
  хранилище) внедряется параметрами — ядро не знает про DOM и `localStorage`;
- **Vitest** — 266 модульных тестов (TDD: сначала падающий тест, затем реализация);
- **ESLint + Prettier + Husky**: `pre-commit` — lint-staged, `pre-push` — полный
  запуск тестов.

## Запуск

```bash
npm install
npm run build
```

Так как это ES-модули, открывать `file://` нельзя — поднимите любой статический
сервер в корне проекта и откройте `index.html`, например:

```bash
npx http-server .
# или
python3 -m http.server
```

## Деплой

Автоматический деплой на GitHub Pages настроен через GitHub Actions
(`.github/workflows/deploy-pages.yml`): каждый `push` в ветку `bulls-and-cows`
прогоняет линтер и тесты, собирает `tsc` и публикует файлы `index.html`,
`styles.css` и каталог `dist/` на <https://al-exxx.github.io/Bulls-and-Cows/>.
Источник публикации в настройках Pages — «GitHub Actions».

## Скрипты

| Команда                | Что делает                             |
| ---------------------- | -------------------------------------- |
| `npm run build`        | компиляция `src/` → `dist/` (tsc)      |
| `npm test`             | однократный прогон тестов (vitest run) |
| `npm run lint`         | ESLint по всему проекту                |
| `npm run format`       | Prettier-форматирование                |
| `npm run format:check` | проверка форматирования                |

## Структура проекта

```
├── index.html          — пустой <body> + <script type="module"> (UI генерируется кодом)
├── styles.css          — стили и адаптивность (media-запросы)
├── DESIGN.md           — архитектура, структуры данных, алгоритмы и Big O
├── .github/workflows/  — CI: тесты и автодеплой на GitHub Pages при push
└── src/
    ├── main.ts         — контроллер: состояние игры + полный ре-рендер экранов
    ├── game/           — чистое ядро (без DOM и localStorage)
    │   ├── types.ts / constants.ts — типы, алфавит цифр, лимиты
    │   ├── validate.ts — createDigitValidator (каррирование), isValidGuess
    │   ├── secret.ts   — generateSecret (рекурсивная выборка без повторов)
    │   ├── evaluate.ts — evaluateGuess (быки/коровы)
    │   ├── counting.ts — countPossibleSecrets (с мемоизацией)
    │   ├── state.ts    — startRound, registerAttempt (иммутабельно)
    │   ├── records.ts  — addRecord (топ-10), safeParseRecords
    │   ├── time.ts     — elapsedMs, formatDuration
    │   └── *.test.ts   — тесты ядра
    ├── storage/        — безопасный адаптер хранилища (ключ на пару length+base)
    └── ui/             — экраны на DOM API (без innerHTML)
        ├── dom.ts      — хелперы el()/clearNode
        ├── settings.ts — экран настроек
        ├── game.ts     — игровой экран (ввод, ошибки, таймер, история, победа)
        └── records.ts  — таблица рекордов
```

Подробнее об архитектуре, сложности алгоритмов и принятых решениях —
в [DESIGN.md](./DESIGN.md).
